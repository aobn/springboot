# 图片验证码接口文档

## 接口概述

图片验证码接口提供验证码图片生成和验证功能，用于防止机器人攻击和提高系统安全性。

## 基础信息

- **Base URL**: `http://localhost:8080/api/verification`
- **Content-Type**: `application/json`
- **字符编码**: `UTF-8`

## 1. 生成图片验证码

### 基本信息

- **接口标识**: `CAPTCHA_GENERATE`
- **请求路径**: `GET /captcha`
- **接口描述**: 生成图片验证码，返回验证码ID和Base64编码的图片
- **认证要求**: 无需认证（公开接口）

### 请求参数

无需请求参数

### 响应示例

#### 成功响应（状态码 200）

```json
{
  "code": 200,
  "message": "图片验证码生成成功",
  "data": {
    "captchaId": "captcha_1725364800000_1234",
    "imageBase64": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAG4AAAAoCAYAAAAIeF9DAAAFxklEQVR4Xu2c...",
    "expireTime": "2025-09-03T20:35:00"
  },
  "timestamp": "2025-09-03T20:30:00Z"
}
```

#### 失败响应（状态码 500）

```json
{
  "code": 500,
  "message": "生成图片验证码失败: 系统内部错误",
  "data": null,
  "timestamp": "2025-09-03T20:30:00Z"
}
```

### 响应字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| captchaId | string | 验证码唯一标识，用于后续验证 |
| imageBase64 | string | Base64编码的验证码图片，可直接在前端显示 |
| expireTime | string | 验证码过期时间（ISO 8601格式） |

## 2. 验证图片验证码

### 基本信息

- **接口标识**: `CAPTCHA_VERIFY`
- **请求路径**: `POST /verify-captcha`
- **接口描述**: 验证用户输入的图片验证码是否正确
- **认证要求**: 无需认证（公开接口）

### 请求参数

```typescript
interface CaptchaVerifyRequest {
  captchaId: string;    // 验证码ID，从生成接口获取
  code: string;         // 用户输入的验证码，4位字符
}
```

### 参数验证规则

```json
{
  "captchaId": {
    "required": true,
    "type": "string",
    "message": "验证码ID不能为空"
  },
  "code": {
    "required": true,
    "type": "string",
    "minLength": 1,
    "maxLength": 10,
    "message": "验证码不能为空"
  }
}
```

### 请求示例

```json
{
  "captchaId": "captcha_1725364800000_1234",
  "code": "A3B7"
}
```

### 响应示例

#### 成功响应（状态码 200）

```json
{
  "code": 200,
  "message": "图片验证码验证成功",
  "data": true,
  "timestamp": "2025-09-03T20:32:00Z"
}
```

#### 失败响应

- **参数验证失败（400）**

```json
{
  "code": 400,
  "message": "验证码ID和验证码不能为空",
  "data": false,
  "timestamp": "2025-09-03T20:32:00Z"

```

- **验证码无效（400）**

```json
{
  "code": 400,
  "message": "图片验证码无效或已过期",
  "data": false,
  "timestamp": "2025-09-03T20:32:00Z"
}
```

## 业务规则

### 验证码特性

1. **验证码长度**: 4位字符
2. **字符范围**: 0-9数字和A-Z大写字母
3. **有效期**: 5分钟
4. **一次性使用**: 验证成功后自动失效
5. **大小写不敏感**: 用户输入时忽略大小写

### 安全机制

1. **防重放**: 每个验证码只能使用一次
2. **时效性**: 超过5分钟自动失效
3. **自动清理**: 系统每5分钟清理一次过期验证码
4. **图片干扰**: 包含干扰线和水波纹效果，防止机器识别

## 前端集成示例

### HTML显示验证码

```html
<div class="captcha-container">
  <img id="captchaImage" src="" alt="验证码" onclick="refreshCaptcha()">
  <input type="text" id="captchaInput" placeholder="请输入验证码" maxlength="4">
  <button onclick="verifyCaptcha()">验证</button>
</div>
```

### JavaScript集成

```javascript
let currentCaptchaId = null;

// 获取验证码
async function getCaptcha() {
  try {
    const response = await fetch('/api/verification/captcha');
    const result = await response.json();
    
    if (result.code === 200) {
      currentCaptchaId = result.data.captchaId;
      document.getElementById('captchaImage').src = result.data.imageBase64;
    } else {
      alert('获取验证码失败: ' + result.message);
    }
  } catch (error) {
    console.error('获取验证码错误:', error);
    alert('获取验证码失败');
  }
}

// 刷新验证码
function refreshCaptcha() {
  getCaptcha();
}

// 验证验证码
async function verifyCaptcha() {
  const code = document.getElementById('captchaInput').value;
  
  if (!code) {
    alert('请输入验证码');
    return;
  }
  
  if (!currentCaptchaId) {
    alert('请先获取验证码');
    return;
  }
  
  try {
    const response = await fetch('/api/verification/verify-captcha', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        captchaId: currentCaptchaId,
        code: code
      })
    });
    
    const result = await response.json();
    
    if (result.code === 200 && result.data === true) {
      alert('验证码验证成功');
      // 继续后续业务逻辑
    } else {
      alert('验证码验证失败: ' + result.message);
      refreshCaptcha(); // 验证失败后刷新验证码
    }
  } catch (error) {
    console.error('验证验证码错误:', error);
    alert('验证验证码失败');
  }
}

// 页面加载时获取验证码
window.onload = function() {
  getCaptcha();
};
```

- **预期响应**: code=200，data包含captchaId、imageBase64、expireTime

### 测试用例2：成功验证验证码

- **前置条件**: 先调用生成接口获取验证码
- **请求**: `POST /api/verification/verify-captcha`
- **请求体**: `{"captchaId":"captcha_xxx","code":"正确的验证码"}`
- **预期响应**: code=200，data=true

- **请求**: `POST /api/verification/verify-captcha`
- **请求体**: `{"captchaId":"captcha_xxx","code":"错误验证码"}`

### 测试用例4：验证码过期

- **前置条件**: 等待验证码过期（5分钟后）
- **请求**: `POST /api/verification/verify-captcha`
- **预期响应**: code=400，message="图片验证码无效或已过期"

### 测试用例5：参数缺失

- **请求**: `POST /api/verification/verify-captcha`
- **请求体**: `{"captchaId":"","code":""}`
- **预期响应**: code=400，message="验证码ID和验证码不能为空"

## 注意事项

1. **验证码区分大小写**: 后端会自动转换为大写进行比较
2. **及时刷新**: 验证失败后建议刷新验证码
3. **错误处理**: 前端需要处理网络错误和业务错误
4. **用户体验**: 提供点击图片刷新验证码的功能
5. **安全考虑**: 不要在前端日志中输出验证码内容
