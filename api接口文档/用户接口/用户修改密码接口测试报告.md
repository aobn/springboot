# 用户修改密码接口测试报告

## 测试概述

- **接口名称**: 用户修改密码接口
- **接口路径**: `POST /api/users/change-password`
- **测试时间**: 2025-01-09
- **测试环境**: 本地开发环境 (localhost:8080)
- **测试工具**: curl命令行工具

## 测试前准备

### 1. 启动应用服务
```bash
cd /root/springboot
./start-springboot.sh
```

### 2. 获取测试用户JWT令牌
首先需要登录获取有效的JWT令牌用于测试：

```bash
# 用户登录获取JWT令牌
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "allnotice@qq.com",
    "password": "12345678"
  }'
```

预期响应：
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "user": {
      "id": 1,
      "username": "allnotice",
      "email": "allnotice@qq.com",
      "role": "USER"
    }
  },
  "timestamp": "2025-01-09T10:30:00Z"
}
```

## 测试用例

### 测试用例1：成功修改密码

**测试目标**: 验证用户能够成功修改密码

**测试步骤**:
```bash
curl -X POST http://localhost:8080/api/users/change-password \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..." \
  -d '{
    "oldPassword": "12345678",
    "newPassword": "newPassword123",
    "confirmPassword": "newPassword123"
  }'
```

**预期结果**:
- HTTP状态码: 200
- 响应体:
```json
{
  "code": 200,
  "message": "密码修改成功",
  "data": null,
  "timestamp": "2025-01-09T10:30:00Z"
}
```

**验证步骤**: 使用新密码重新登录验证密码是否修改成功

### 测试用例2：原密码错误

**测试目标**: 验证原密码错误时的错误处理

**测试步骤**:
```bash
curl -X POST http://localhost:8080/api/users/change-password \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..." \
  -d '{
    "oldPassword": "wrongPassword",
    "newPassword": "newPassword123",
    "confirmPassword": "newPassword123"
  }'
```

**预期结果**:
- HTTP状态码: 400
- 响应体:
```json
{
  "code": 400,
  "message": "密码修改失败，请检查原密码是否正确",
  "data": null,
  "timestamp": "2025-01-09T10:30:00Z"
}
```

## 测试环境信息

- **操作系统**: Linux Ubuntu

- **数据库**: MySQL 8.0

## 注意事项

1. **测试数据恢复**: 每次测试后需要将测试用户密码恢复为原始密码
2. **令牌有效期**: JWT令牌有24小时有效期，测试时注意令牌是否过期
3. **数据库状态**: 确保测试用户存在于数据库中
4. **日志监控**: 测试过程中监控应用日志，确保没有异常错误
