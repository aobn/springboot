# 用户忘记密码修改密码接口

## 基本信息

- **接口标识**：`AUTH_FORGOT_PASSWORD`
- **请求路径**：`POST /api/auth/forgot-password`
- **接口描述**：用户通过邮箱验证码重置密码，无需提供原密码
- **认证要求**：无需认证（公开接口）
- **适用业务单元**：用户密码重置流程

## 请求参数

### 请求体格式
```json
{
  "email": "string",
  "verificationCode": "string", 
  "newPassword": "string",
  "confirmPassword": "string"
}
```

### 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| email | string | 是 | 用户邮箱地址，必须是已注册的邮箱 |
| verificationCode | string | 是 | 邮箱验证码，6位数字 |
| newPassword | string | 是 | 新密码，8-32位字符 |
| confirmPassword | string | 是 | 确认新密码，必须与newPassword一致 |

### 参数验证规则

```json
{
  "email": {
    "required": true,
    "type": "email",
    "message": "请输入有效的邮箱地址"
  },
  "verificationCode": {
    "required": true,
    "type": "string",
    "length": 6,
    "pattern": "^[0-9]{6}$",
    "message": "验证码必须为6位数字"
  },
  "newPassword": {
    "required": true,
    "type": "string",
    "minLength": 8,
    "maxLength": 32,
    "message": "密码长度必须在8-32位之间"
  },
  "confirmPassword": {
    "required": true,
    "type": "string",
    "custom": "mustMatchNewPassword",
    "message": "确认密码必须与新密码一致"
  }
}
```

## 业务流程

1. **前置条件**：用户已通过邮箱验证码接口获取验证码
2. **验证步骤**：
   - 验证请求参数格式和完整性
   - 验证新密码和确认密码是否一致
   - 验证邮箱验证码是否有效
   - 检查邮箱是否已注册
   - 检查用户账户状态（是否被封禁）
   - 检查新密码是否与原密码相同
3. **执行操作**：
   - 更新用户密码（加密存储）
   - 标记验证码为已使用
4. **返回结果**：成功或失败信息

## 安全考虑

1. **验证码安全**：
   - 验证码有效期限制（通常5-10分钟）
   - 验证码使用后立即失效
   - 防止验证码暴力破解

2. **密码安全**：
   - 密码长度限制（8-32位）
   - 密码加密存储（BCrypt）
   - 防止新密码与原密码相同

3. **账户安全**：
   - 检查账户状态（封禁用户无法修改密码）
   - 操作日志记录
