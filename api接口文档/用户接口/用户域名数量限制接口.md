# 用户域名数量限制接口文档

## 概述
本文档描述用户域名数量限制功能相关的API接口。该功能限制每个用户默认只能注册2个域名，支持管理员调整用户配额。

## 接口列表

### 1. 获取用户域名统计信息
**接口地址：** `GET /api/user/subdomains/stats/mine`

**功能描述：** 获取当前登录用户的域名使用统计信息

**请求头：**
```
Authorization: Bearer {JWT_TOKEN}
Content-Type: application/json
```

**响应示例：**
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "id": 1,
    "username": "testuser",
    "email": "test@example.com",
    "availableDomains": 1,
    "usedDomains": 1,
    "registrationStatus": "CAN_REGISTER"
  },
  "timestamp": "2025-09-10T20:00:00Z"
}
```

**响应字段说明：**
- `availableDomains`: 剩余可注册域名数量
- `usedDomains`: 已使用域名数量
- `registrationStatus`: 注册状态（CAN_REGISTER/LIMIT_REACHED）

---

### 2. 检查是否可以注册域名
**接口地址：** `GET /api/user/subdomains/can-register`

**功能描述：** 检查当前用户是否还能注册新域名

**请求头：**
```
Authorization: Bearer {JWT_TOKEN}
Content-Type: application/json
```

**响应示例：**
```json
{
  "code": 200,
  "message": "操作成功",
  "data": true,
  "timestamp": "2025-09-10T20:00:00Z"
}
```

---

### 3. 获取剩余可注册域名数量
**接口地址：** `GET /api/user/subdomains/remaining-count`

**功能描述：** 获取当前用户剩余可注册的域名数量

**请求头：**
```
Authorization: Bearer {JWT_TOKEN}
Content-Type: application/json
```

**响应示例：**
```json
{
  "code": 200,
  "message": "操作成功",
  "data": 1,
  "timestamp": "2025-09-10T20:00:00Z"
}
```

---

### 4. 用户注册域名（已更新）
**接口地址：** `POST /api/user/subdomains/register`

**功能描述：** 用户注册3级域名，现在会检查域名数量限制

**请求头：**
```
Authorization: Bearer {JWT_TOKEN}
Content-Type: application/json
```

**请求体：**
```json
{
  "subdomain": "mysite",
  "domain": "cblog.eu"
}
```

**成功响应：**
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "id": 1,
    "userId": 1,
    "subdomain": "mysite",
    "domain": "cblog.eu",
    "fullDomain": "mysite.cblog.eu",
    "status": "ACTIVE",
    "remark": "test@example.com",
    "createTime": "2025-09-10T20:00:00",
    "updateTime": "2025-09-10T20:00:00"
  },
  "timestamp": "2025-09-10T20:00:00Z"
}
```

**达到限制时的错误响应：**
```json
{
  "code": 400,
  "message": "您已达到域名注册数量上限，当前可注册数量：0",
  "data": null,
  "timestamp": "2025-09-10T20:00:00Z"
}
```

## 管理员接口

### 5. 调整用户域名配额（SQL操作）
**功能描述：** 管理员可以通过数据库操作调整用户的域名配额

**SQL示例：**
```sql
-- 将用户ID为1的用户域名配额增加到5个
UPDATE user SET dom_num = 5 WHERE id = 1;

-- 批量调整VIP用户配额
UPDATE user SET dom_num = 10 WHERE role = 'VIP';
```

---

## 数据库触发器

### 自动域名数量管理
系统通过数据库触发器自动管理用户的域名数量：

1. **插入触发器：** 用户成功注册域名时，自动减少`dom_num`
2. **删除触发器：** 用户删除域名时，自动增加`dom_num`
3. **更新触发器：** 域名状态变更时，自动调整`dom_num`

### 统计视图
```sql
-- 查看用户域名使用统计
SELECT * FROM v_user_domain_stats WHERE user_id = 1;
```

---

## 错误码说明

| 错误码 | 错误信息 | 说明 |
|--------|----------|------|
| 400 | 您已达到域名注册数量上限，当前可注册数量：0 | 用户域名配额已用完 |
| 400 | 用户不存在 | 用户ID无效 |
| 400 | 域名 xxx.cblog.eu 已存在 | 域名已被注册 |
| 401 | JWT解析失败 | 令牌无效或过期 |
| 500 | 注册域名失败：xxx | 系统内部错误 |

## 测试用例

### 测试场景1：正常注册域名
```bash
# 1. 检查剩余配额
curl -X GET "http://localhost:8080/api/user/subdomains/remaining-count" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

# 2. 注册第一个域名
curl -X POST "http://localhost:8080/api/user/subdomains/register" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"subdomain": "test1", "domain": "cblog.eu"}'

# 3. 检查统计信息
curl -X GET "http://localhost:8080/api/user/subdomains/stats/mine" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

### 测试场景2：达到限制
```bash
# 注册第二个域名
curl -X POST "http://localhost:8080/api/user/subdomains/register" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"subdomain": "test2", "domain": "cblog.eu"}'

# 尝试注册第三个域名（应该失败）
curl -X POST "http://localhost:8080/api/user/subdomains/register" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"subdomain": "test3", "domain": "cblog.eu"}'
```

## 实现特点

1. **数据库层面保证一致性：** 使用触发器自动管理域名数量
2. **应用层双重验证：** 注册前检查配额，提供友好错误信息
3. **灵活的配额管理：** 支持管理员调整用户配额
4. **完整的统计信息：** 提供详细的域名使用统计
5. **向后兼容：** 不影响现有功能，平滑升级

---

## 注意事项

1. 默认每个用户可注册2个域名
2. 删除域名会自动恢复配额
3. 域名状态变更会影响配额计算
4. 管理员可以灵活调整用户配额
5. 所有操作都有完整的日志记录
