## 发送邮箱验证码接口测试定义



## 请求实例

```
curl  -X POST 'https://mail.webdom.cn:41443/api/batch_mail/api/send' \
-H 'X-API-Key: e70a3ac47d0631360c4b11f25d2a431e3264ba45ac2bbbecc9a8003f3b2ae1e7' \
-H 'Content-Type: application/json' \
-d '{
	"recipient": "allnotice@qq.com",
	 "attribs": {
        "verification_code": "325323"
    }
}'
```

 **参数说明：**

| 参数              | 类型     | 必填 | 说明               |
| :---------------- | :------- | :--- | :----------------- |
| recipients        | string[] | 是   | 收件人邮箱地址数组 |
| verification_code | string   | 是   | 邮箱验证码         |

> 

## 响应实例

```
{"success":true,"code":0,"msg":"电子邮件已成功发送","data":null}  
```



 **状态码说明: **

| code     | 说明         | 解决方案               |
| :------- | :----------- | :--------------------- |
| **1001** | API密钥无效  | 检查API密钥是否正确    |
| **1002** | IP不允许     | 检查是否设置了ip白名单 |
| **1003** | 收件人无效   | 检查邮箱地址格式       |
| **1004** | 模板不存在   | 检查模板ID             |
| **1005** | 发送失败     | 查看详细错误日志       |
| 0        | 邮件发送成功 | 无                     |
