# 获取当前用户域名列表接口文档

## 接口概述
该接口用于获取当前登录用户的所有域名列表，包括DNSPod 3级域名和Cloudflare域名，支持按状态过滤。

## 接口详情

### 获取当前用户的所有域名列表（推荐使用）

**接口地址：** `GET /api/user/subdomains/list/mine`

**请求方式：** GET

**Content-Type：** `application/json`

**认证方式：** Bearer Token（JWT）

**请求头：**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Authorization | String | 是 | Bearer {token} |

**请求参数：**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| status | String | 否 | 域名状态过滤（ACTIVE-活跃，INACTIVE-不活跃，DELETED-已删除）。不提供则返回所有非删除状态的域名 |

**请求示例：**
```bash
# 获取所有域名
curl -X GET "http://localhost:8001/api/user/subdomains/list/mine" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."

# 获取活跃状态的域名
curl -X GET "http://localhost:8001/api/user/subdomains/list/mine?status=ACTIVE" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

## 业务流程

### 查询流程
1. **身份验证**：验证JWT token的有效性
2. **提取用户信息**：从token中获取用户ID
3. **域名查询**：
   - 如果提供了status参数，则按用户ID和状态查询
   - 如果未提供status参数，则查询用户所有非删除状态的域名
4. **返回结果**：返回查询到的域名列表

## 字段说明

### DNSPod域名字段
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | Long | 域名记录主键ID |
| userId | Long | 用户ID |
| subdomain | String | 子域名前缀 |
| domain | String | 主域名 |
| fullDomain | String | 完整域名 |
| status | String | 状态（ACTIVE-活跃，INACTIVE-不活跃，DELETED-已删除） |
| remark | String | 备注信息 |
| createTime | String | 创建时间 |
| updateTime | String | 更新时间 |
| type | String | 域名类型，固定值"DNSPOD" |

### Cloudflare域名字段
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | Long | 域名记录主键ID |
| userId | Long | 用户ID |
| zoneId | String | Cloudflare Zone ID |
| zoneName | String | 域名名称 |
| assignedPrefix | String | 分配的前缀 |
| fullSubdomain | String | 完整子域名 |
| status | String | 状态（ACTIVE-活跃，INACTIVE-不活跃，DELETED-已删除） |
| dnsRecordCount | Integer | DNS记录数量 |
| dnsRecordLimit | Integer | DNS记录限制 |
| dnsUsagePercent | Double | DNS使用率百分比 |
| remark | String | 备注信息 |
| assignedTime | String | 分配时间 |
| type | String | 域名类型，固定值"CLOUDFLARE" |

### 统计信息字段
| 字段名 | 类型 | 说明 |
|--------|------|------|
| availableDomains | Integer | 用户可注册域名数量 |
| dnspodDomainsCount | Integer | DNSPod域名数量 |
| cloudflareDomainsCount | Integer | Cloudflare域名数量 |
| totalDomainsCount | Integer | 总域名数量 |
| registrationStatus | String | 注册状态（CAN_REGISTER-可注册，LIMIT_REACHED-已达上限） |

## 错误处理

### 参数验证错误
- JWT token无效或过期
- Authorization头缺失
- status参数值无效

### 业务逻辑错误
- 用户权限不足
- 数据库操作失败

## 安全考虑

1. **JWT认证**：必须提供有效的JWT token
2. **用户隔离**：只能查询当前登录用户的域名
3. **数据过滤**：默认不返回已删除的域名

## 功能特性

### 统一域名管理
- **多平台支持**：同时支持DNSPod和Cloudflare域名
- **统一接口**：一个接口获取所有类型的域名
- **状态过滤**：支持按状态过滤所有类型的域名
- **统计信息**：提供详细的域名使用统计

### 向后兼容
- **兼容接口**：保留`/dnspod`子路径接口，确保旧版本兼容
- **数据格式**：DNSPod域名保持原有数据格式
- **功能完整**：新接口包含所有原有功能

## 使用场景

1. **统一域名管理**：用户在一个接口中查看所有平台的域名

## 注意事项

1. **认证要求**：接口需要JWT认证，请确保token有效
2. **状态过滤**：默认情况下不返回状态为DELETED的域名
3. **排序规则**：域名列表按创建/分配时间降序排列
4. **状态值**：status参数值必须是有效的状态值（ACTIVE、INACTIVE、DELETED）
5. **数据完整性**：统计信息实时计算，确保数据准确性
6. **性能考虑**：接口会查询多个数据源，响应时间可能稍长
