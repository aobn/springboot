# 用户域名注册统计接口

## 接口信息
- **接口名称**: 用户域名注册统计接口
- **接口描述**: 获取用户的域名注册数量统计和限制信息
- **请求方法**: GET
- **请求路径**: `/api/user/cloudflare/zones/stats`
- **认证方式**: JWT Token认证

## 请求参数
无需请求参数，用户信息从JWT Token中获取。

## 请求头
```
Authorization: Bearer <JWT_TOKEN>
Content-Type: application/json
```

## 响应格式

### 成功响应 (200)
```json
{
  "code": 200,
  "message": "获取域名统计信息成功",
  "data": {
    "availableDomains": 2,
    "registeredCloudflareZones": 1,
    "registeredDnspodDomains": 0,
    "totalRegisteredDomains": 1,
    "registrationStatus": "CAN_REGISTER"
  },
  "timestamp": "2025-09-27T02:00:00"
}
```

### 响应字段说明
| 字段名 | 类型 | 描述 |
|--------|------|------|
| availableDomains | Integer | 用户可注册域名数量 |
| registeredCloudflareZones | Integer | 已注册的Cloudflare域名数量 |
| registeredDnspodDomains | Integer | 已注册的DNSPod域名数量 |
| totalRegisteredDomains | Integer | 总已注册域名数量 |
| registrationStatus | String | 注册状态：CAN_REGISTER(可以注册)、LIMIT_REACHED(已达上限) |

### 错误响应

#### 401 未授权
```json
{
  "code": 401,
  "message": "未授权访问",
  "data": null,
  "timestamp": "2025-09-27T02:00:00"
}
```

#### 500 服务器错误
```json
{
  "code": 500,
  "message": "系统错误，请稍后重试",
  "data": null,
  "timestamp": "2025-09-27T02:00:00"
}
```

## 业务逻辑说明

1. **域名数量限制**：
   - 用户表中的`dom_num`字段表示用户可注册的域名数量
   - 默认值为2个域名
   - 当用户注册Cloudflare域名时，该数量会减1
   - 当用户注销域名时，该数量会恢复+1

2. **统计计算**：
   - `registeredCloudflareZones`：从`user_cloudflare_domain`表统计状态为ACTIVE的记录
   - `registeredDnspodDomains`：从`user_subdomain`表统计状态为ACTIVE的记录
   - `totalRegisteredDomains`：两者之和
   - `registrationStatus`：根据`availableDomains`是否大于0判断

3. **注册状态**：
   - `CAN_REGISTER`：用户还可以注册新域名
   - `LIMIT_REACHED`：用户已达到注册上限

## 使用场景

1. **前端页面显示**：在用户域名管理页面显示用户的域名使用情况
2. **注册前检查**：在用户尝试注册新域名前检查是否还有可用额度
3. **统计报表**：管理员查看用户域名使用统计

## 注意事项

1. 需要有效的JWT Token才能访问此接口
2. 统计数据实时计算，确保准确性
3. 如果数据库查询异常，会返回默认的安全值（全部为0，状态为LIMIT_REACHED）
