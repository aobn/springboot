# 管理员获取用户列表接口文档

## 基本信息

- **接口标识**: `ADMIN_GET_USERS`
- **接口名称**: 管理员获取用户列表
- **请求方法**: `GET`
- **请求路径**: `/api/admin/users`
- **接口描述**: 管理员获取系统中所有用户的分页列表，支持排序和分页查询
- **权限要求**: 需要ADMIN角色权限

## 请求参数

### 查询参数 (Query Parameters)

| 参数名 | 类型 | 必填 | 默认值 | 描述 | 示例 |
|--------|------|------|--------|------|------|
| page | Integer | 否 | 1 | 页码，从1开始 | 1 |
| size | Integer | 否 | 3000 | 每页数据量，最大3000 | 10 |
| sort | String | 否 | id | 排序字段 | id, username, email, createTime |
| order | String | 否 | ASC | 排序方向 | ASC, DESC |

### 请求头 (Headers)

| 参数名 | 类型 | 必填 | 描述 | 示例 |
|--------|------|------|------|------|
| Authorization | String | 是 | JWT令牌，格式：Bearer {token} | Bearer eyJhbGciOiJIUzI1NiJ9... |

    "hasPrevious": false

### 响应字段说明

#### 用户对象字段 (content数组中的对象)

| 字段名 | 类型 | 描述 |
|--------|------|------|
| id | Long | 用户ID |
| username | String | 用户名 |
| password | null | 密码字段（出于安全考虑，始终为null） |
| email | String | 用户邮箱 |
| role | String | 用户角色（USER） |
| domNum | Integer | 用户域名配额数量 |
| createTime | String | 创建时间（ISO 8601格式） |
| updateTime | String | 更新时间（ISO 8601格式） |

#### 分页信息字段

| 字段名 | 类型 | 描述 |
|--------|------|------|
| content | Array | 用户数据数组 |
| page | Integer | 当前页码 |
| size | Integer | 每页数据量 |
| total | Long | 总记录数 |
| totalPages | Integer | 总页数 |
| first | Boolean | 是否为第一页 |
| last | Boolean | 是否为最后一页 |
| hasNext | Boolean | 是否有下一页 |
| hasPrevious | Boolean | 是否有上一页 |

## 请求示例

### 示例1：获取默认分页数据（3000条）
```bash
curl -X GET "http://localhost:8080/api/admin/users" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

### 示例2：获取第1页，每页5条数据
```bash
curl -X GET "http://localhost:8080/api/admin/users?page=1&size=5" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

### 示例3：按ID降序排列，获取第2页
```bash
curl -X GET "http://localhost:8080/api/admin/users?page=2&size=5&sort=id&order=DESC" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

### 示例4：按创建时间降序排列
```bash
curl -X GET "http://localhost:8080/api/admin/users?sort=createTime&order=DESC" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

## 功能特性

### ✅ 已实现功能

1. **分页查询**
   - 支持自定义页码和每页数据量
   - 默认每页3000条数据
   - 提供完整的分页信息

2. **排序功能**
   - 支持按多个字段排序（id、username、email、createTime等）
   - 支持升序（ASC）和降序（DESC）排序

3. **权限控制**
   - 仅限ADMIN角色访问
   - JWT令牌认证

4. **数据安全**
   - 密码字段始终返回null
   - 完整的用户信息展示

5. **性能优化**
   - 使用LIMIT和OFFSET进行数据库分页
   - 避免一次性加载大量数据

## 业务逻辑

1. **权限验证**: 验证请求者是否具有ADMIN角色
2. **参数校验**: 验证分页参数的合法性
3. **数据查询**: 根据分页参数查询用户数据
4. **数据处理**: 清除敏感信息（密码）
5. **响应构建**: 构建包含分页信息的响应

## 注意事项

1. **默认配置**: 默认每页3000条数据，适合管理员批量操作
2. **最大限制**: 每页最大3000条数据，防止内存溢出
3. **排序字段**: 确保排序字段存在于数据库表中
4. **权限要求**: 必须使用有效的ADMIN角色JWT令牌
