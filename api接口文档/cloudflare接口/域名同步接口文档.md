# Cloudflare域名同步接口文档

## 接口概述
本文档描述了Cloudflare域名数据同步相关的API接口，包括从Cloudflare获取域名数据并同步到本地数据库的功能。

## 基础信息
- **基础URL**: `http://localhost:8080/api/cloudflare`
- **认证方式**: JWT Token (Bearer Token)
- **权限要求**: 管理员权限 (ADMIN)

## 接口列表

### 1. 同步Cloudflare域名数据

**接口描述**: 从Cloudflare API获取所有域名数据并同步到本地数据库

**请求信息**:
- **URL**: `POST /sync-zones`
- **方法**: POST
- **认证**: 需要管理员JWT Token

**请求头**:
```http
Authorization: Bearer <JWT_TOKEN>
Content-Type: application/json
```

**响应示例**:
```json
{
  "code": 200,
  "message": "成功同步 5 个Cloudflare域名到本地数据库",
  "data": null,
  "timestamp": "2025-09-25T22:43:00"
}
```

**错误响应**:
```json
{
  "code": 403,
  "message": "需要管理员权限才能同步域名数据",
  "data": null,
  "timestamp": "2025-09-25T22:43:00"
}
```

## 使用流程

### 1. 首次同步域名数据
1. 获取管理员JWT Token
2. 调用 `POST /sync-zones` 接口同步域名数据
3. 调用 `GET /local-zones` 接口查看同步结果

### 2. 查询本地域名信息
1. 使用 `GET /local-zones` 获取所有域名列表
2. 使用 `GET /local-zones/{zoneName}` 获取特定域名详情

### 3. 定期同步更新
建议定期调用 `POST /sync-zones` 接口来保持本地数据与Cloudflare的同步。

## 错误码说明

| 错误码 | 说明 |
|--------|------|
| 200 | 请求成功 |
| 400 | 请求参数错误 |
| 401 | 未授权，Token无效或过期 |
| 403 | 权限不足，需要管理员权限 |
| 404 | 资源未找到 |
| 500 | 服务器内部错误 |

## 注意事项

1. **权限要求**: 所有接口都需要管理员权限
2. **数据同步**: 同步操作会覆盖本地已存在的域名数据
3. **性能考虑**: 同步操作可能需要一定时间，建议异步处理
4. **错误处理**: 如果Cloudflare API调用失败，会返回相应的错误信息
5. **数据完整性**: 本地数据库会保存完整的Cloudflare域名信息，包括元数据

## 数据库表结构

域名数据存储在 `cloudflare_zone` 表中，包含以下主要字段：
- 基本信息：zone_id, name, status, type
- 服务器信息：name_servers, original_name_servers
- 时间信息：created_on, modified_on, activated_on
- 账户信息：account_id, account_name
- 计划信息：plan_id, plan_name, plan_price
- 同步状态：sync_status, last_sync_time
- 本地管理：is_active, create_time, update_time
