## 测试概述

- **接口名称**：发送邮箱验证码（使用外部邮件服务）
- **接口地址**：POST /api/verification/send-code
- **测试时间**：2025-09-15 04:37:00

## 功能更新说明

### 原有实现问题
- 使用Spring Mail + SMTP服务器发送邮件
- 存在邮件认证失败问题（535 Error: authentication failed）
- 依赖本地邮件服务器配置

### 新实现方案
- 使用外部邮件API服务：`https://mail.webdom.cn:41443/api/batch_mail/api/send`
- API密钥认证：`e70a3ac47d0631360c4b11f25d2a431e3264ba45ac2bbbecc9a8003f3b2ae1e7`
- 支持模板化邮件发送
- 更稳定的邮件投递率

1. **ExternalMailService.java** - 外部邮件服务接口
2. **ExternalMailServiceImpl.java** - 外部邮件服务实现类
